## 核心定義

- **內部大戶 = 非法人大戶**（老簡自創詞）：集保股權分散表（TDCC，每週六公布）大戶級距的變化，
  扣掉法人大戶買賣超。「知道公司內情的有實力大戶」— 可能是同業、上下游老闆、退休高層。
- **大戶門檻用金額**（基準：單一持股 ≥2000 萬）：
  - 股價 ≥50 元 → 看 400 張級距（沿用神秘金字塔的分法）
  - 股價 20~50 元 → 看 1000 張級距
  - 千元股 → 100 張就夠（EP75 訪談）
- **公式**：內部大戶買賣超 ＝ 近週大戶級距持股 − 前週 − 法人大戶買賣超。
  注意他明說 APP「不只減三大法人，還有壽險，且非所有法人都是大戶，公式有參數調整」→ 有私有成分，外部無法完全復刻。

## APP 選股流程

1. **每週六早上更新**（TDCC 週六凌晨公布；資料統計到週四，T+1 延遲）
2. **剔除股權變化**（增資/可轉債換股的週直接不進排名）
3. 三種排名：**買超集中股**＝內部大戶買超÷股本%（主用）；**主力重壓股**＝買超金額（次用）；
   持股暴增（張數）少用 — 大型股會佔榜且「內部大戶對大型股效果不好」
4. **報買訊號：單週買超 > 股本 2%**（8 年回測宣稱：無腦買、3-6 個月無腦賣、平均 +14%）
5. **四象限掃一遍**：高價/低價 × 熱門（日均量>1000張）/冷門（<1000 張；<100 張太冷不選）
6. **族群效應**：排名前段同族群整片籌碼好 → 加信心（設備股案例）
7. 篩選欄推薦：**月營收創新高**（進攻型；他早期只買這個）、殖利率>3%（保守型）；
   但實務「寧寬勿窄」，不設營收硬門檻、用族群判斷
8. **零軸累積曲線**：內部大戶累積買超% — 累積 >5% 好標的、**累積創新高**＝強訊號、−6%＝跑光
9. 冷門股突然單週大買 ＝ 他最愛的起漲訊號（系統電 6 元、愛普 50 元案例）
10. 分點複驗：用券商分點排除**隔日沖**誤入（統計到週四、週五沖掉看不到）

## 出場（兩條件同時成立才走）

1. 股價漲到合理區間（預估 EPS × 合理本益比）
2. 內部大戶連續賣超一段時間／持股水位跌破零軸

## 其他用法與限制（他自己講的）

- 檢視持倉：週六看自選股內部大戶買賣超，賣超→考慮減碼
- 業績預測：月底月初看內部大戶動向猜下月營收（自稱 80% 準）
- 克服技術分析盲點：基本面+籌碼都好，破線不用怕
- **不能反向做空**：內部大戶跑光常是法人還在做莊，要等法人認錯
- 已知盲點：T+1 延遲、隔日沖污染、庫藏股混入、400/1000 級距內部流轉看不清、大型股無效
- 自稱勝率 80%、90% 飆股前有內部大戶痕跡（行銷數字，無法驗證）

## 買賣策略總結 SOP（忠實整理版）

### 每週六早上：掃描（TDCC 更新後）

1. 開 APP 看**買超集中排名**（內部大戶買超÷股本%），四象限各掃一遍：
   高價熱門 → 低價熱門 → 高價冷門 → 低價冷門（熱門=日均量>1000張；<100張太冷不碰）
2. 圈出候選，優先順序：
   - **報買**（單週買超 > 股本 2%）＝最強
   - 主力重壓（買超金額大）
   - 冷門股突然單週大買（起漲點型態，他的最愛）
   - 內部大戶**累積曲線創新高**、或累積 >5%
   - 法人大賣但股價跌不下去（＝內部大戶在接）
3. 加分：同族群整片籌碼都好（族群效應）
4. 直接跳過：大型權值股（無效）、股權變化股（APP 已剔）

### 買前驗證（基本面為盾，兩邊都好才買）

5. 量化：月營收**持續**創新高、毛利率**持續**成長
6. 質化：產業龍頭、同業中毛利率最好、有定價權護城河
7. 估值：預估 EPS × 合理 PE 推合理區間，確認現價仍在低估～合理下緣
8. 反向檢查：公司說很樂觀但內部大戶在賣 → 不買
9. 排雷（券商分點複驗）：買的是隔日沖分點（週四買、週五沖）→ 剔除；庫藏股混入 → 剔除
10. 進場：下週一開盤後；他自己每週頂多買一檔，錢少就集中

### 持有中（每週六例行檢視）

- 自選股清單看內部大戶：買超 → 安心續抱；賣超 → 警戒但先看**水位**——
  累積持股%還高就不急著跑（泰博案例）
- 跌破均線/破底但基本面+籌碼都好 → 不理會（克服技術分析盲點）
- 月底月初：用內部大戶動向預判下月營收（提前卡位或提前警戒）
- 存股型趨勢股（台積電/台達電/聯發科類）不看籌碼，抱產業趨勢；
  籌碼的價值只是「縮短等待時間」

### 賣出（兩條件**同時**成立才走）

1. 股價漲到合理區間（預估 EPS × 合理 PE）
2. 內部大戶**連續賣超**一段時間／持股水位跌破零軸（−6% ≈ 跑光）

補充規則：
- 新手練功法：+30% 停利換股輪動（一次一檔，三次 30% ≈ 一年翻倍）；熟練後改抱整個趨勢
- 賺到 3 倍：強制做一次「二次確認」再決定續抱
- 大盤系統性「那根針」真的刺破（不是預設點位）→ 勇敢全跑
- **不反向做空**：內部大戶跑光常是法人還在做莊，要等法人認錯才空

### 心法三句

- 基本面為盾、籌碼面為矛
- 買股票要忘本：忘記成本，只看未來營收/毛利會不會續創高
- 週更資料＝長線工具，短線/當沖/技術派不適用

## rockstock 誠實回測結論（2026-07-03，scripts/backtest-insider-whale.ts）

資料 2024-01 ~ 2026-06（TDCC 快取起點限制，測不到他宣稱的 8 年），週度事件、
次交易日開盤進場、超額對 ^TWII、時間中位 train/test 對切：

- **忠實參數（報買>2%、剔股權變化、日均量≥100張宇宙）仍無 alpha**：
  train −0.91% / test −1.69%（d20 超額），勝率 37~40%。
- 持有越久輸越多：d120 test 超額 −15.8%，但 **raw +11.3% — 直接復刻了他宣稱的「+14%」**：
  那是大盤 beta，牛市裡隨便買都有，不是 edge。
- 唯一兩期不翻負的組合：**報買 + 月營收 12 月新高**（train +5.13%/51% → test +0.06%/44%），
  但 test 勝率 <50%、超額 ≈0，且是 ~20 個變體挑出來的倖存者（多重檢定），只能算「不輸大盤」。
  再次呼應全站老規律：**扛報酬的是營收創新高那一半，籌碼是裝飾**。
- 冷門股變體樣本太小（n=19/81）且 train/test 反向，不可信。
- 零軸累積創新高：兩期皆負，比基準更差。
- 避雷側（內部大戶跑）也無料，與價量避雷反向的老規律一致。

**裁決：不進生產、不進主視圖。大戶類因子第四次陣亡**（前三次：S 軌大戶持股%、
陳唯泰大戶連增、內部大戶 v1 門檻版）。方法論上唯一可留的觀察：他的出場二條件
（估值到位＋籌碼轉弱同時成立）與本站「控虧損>選飆股」的北極星方向一致，但買側無效。
