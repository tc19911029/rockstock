## 一、籌碼集中度（核心，徐黎芳影片＋topic 339）

**公式（單一事實）**：集中度 =（區間買超前15名買超合計 − 區間賣超前15名賣超合計）÷ 區間成交量

**門檻（天期越短要越高）**：
- 短線 1/3/5 日：> **20%** 才算有人在收
- 60 日：> **5%**
- 120 日：> **3%**

**5日 vs 20日 交叉表**：
- 5正 20正 = 主力持續買 / 5正 20負 = 短線剛進場 / 5負 20正 = 短線剛出場 / 5負 20負 = 持續賣
- 實戰：**5日集中度連續好幾天 > 20日集中度** → 主力積極買、後續漲（鴻海例 ~14%）
- **價漲但集中度下降 = 假突破，剔除**（呼應我們「不追高」回測）

**紅綠Bar**：紅=買超、綠=賣超；要找「連續多天紅、紅成一片」。官方只說「連續數日」沒給硬根數。

## 三、其他指標單元（門檻 + 我們有沒有資料）

- **三大法人買賣超（393）**：漲<20%可跟、>50%停看聽；中小型股「跟進不跟出」。✅ inst 深歷史
- **融資融券（395）**：中小型股融資暴增=主力；融券創高(大型股)=買訊；融資創高=賣訊。✅ margin 86 天
- **借券（1433）**：股價高檔借券賣出增 = 利空（法人放空）。✅ sbl 86 天
- **當沖（1434）**：當沖比 >20% = 投機過熱；低檔當沖爆量=機會、高檔=風險。⚠️ daytrade 只 2 天
- **周轉率（397）**：60日>50% / 240日>150% = 過熱；低檔周轉變高=起漲。✅ 已會算（捕撈季節）
- **成本線（396）**：成本線之上做多之下做空；短線融資/中線投信/長線外資成本線。✅ lib/chipcost
- **贏家輸家券商（440）**：贏家=賺最多前15券商。買超都贏家=看好、都輸家=將竭盡；賣超都贏家=別期待、都輸家=續漲。⚠️ 需主力分點賺賠，1 週
- **外資 vs 外資券商（394）**：概念課（認假外資），無可量化訊號。❌
- **地緣券商/主力地圖（365/334）**：公司 3 公里內券商異常買=內部消息，3個月內有戲。❌ 無 geo 資料
- **官股護盤（1639）**：政府買官股=還在跌、賣官股=可能要漲。判讀型無門檻
- **PC Power（1430）**：選擇權 CALL−PUT 市值，>±15億=大行情。大盤情緒非個股

## 四、可照做的「組合選股規則」（達人實戰，有數字）

1. **分點選股 7 套（topic 387）**：交易家數>60日均2倍 / 最大買超券商>成交量30% / 集中度>20% / 家數差占比>30% / 融資使用率>60%過熱 / 外資買超>2000張
2. **大戶買散戶賣（CMoney 官方）**：散戶(100張↓)差額<−0.3 **且** 大戶(千張↑)差額>0.3
3. **主力+融資+成本線（喬山1736例）★**：①融資近5日增加 ②股價站上融資成本線 ③**主力連買天數>2**。核心金句：**「主力連買行為比買超量更重要」**
4. **短中長表態股（topic 2680）**：60天家數差50%為負 + 1/5/20/60/120日集中度全>0 + 盤整突噴長紅K。集中度4~18%區間兩月漲29~54%

## 五、對「大戶偷買」策略的下一步（按可測性排序）

**能立刻回測（深歷史資料）**：
1. ⭐ **法人連買天數 > 2**（取代/搭配現用的「5日買超總和」）— 全課程最一致的金句「連買比量重要」。資料 = inst 深歷史 + lib/chips/instDerived.ts
2. **5日集中度 > 20日集中度**（短線加速確認）— inst 算得出
3. **融資近5日變化**（散戶在退 or 主力在進，徐黎芳vs達人說法相反 → 正好回測誰對）— margin 86 天
4. **借券當 veto**（高檔法人放空就避開）— sbl 86 天
5. **站上主力/融資成本線**（進場位置）— lib/chipcost

**只能當「今日清單多看一眼」、還測不動（資料淺/缺）**：
- 主力券商集中度本尊、買賣家數差、贏家輸家券商（主力分點只 1 週）
- 當沖比過熱 veto（daytrade 只 2 天）
- 內部人持股、地緣券商（無資料源）

**結論**：先測 #1「連買天數」最值得 —— 若「法人連買 N 天」比「5日買超總和」更能預測下週漲，就把它換進策略門檻。其餘 2-4 當第二批。
