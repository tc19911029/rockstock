# 全方法誠實總表（2026-06-14）

> 一句話：**「選股贏大盤」幾乎都沒穩定 edge；真正有料的是「避雷（別買）＋ 紀律（停損/出場）」。**
> 所有數字皆「扣手續費、比大盤、train/test 切半」後的誠實值。多數策略勝率 <50%、淨超額很薄。

- **題材∩三色只有台股有用**：陸股交叉超額 −0.22%（只看三色 +0.57% 反而更好），別在陸股用這招。

## 🔴 避雷端：最可信、最強的一塊（程式真正的價值）

這些事後系統性偏弱，**當「別碰」清單比當買訊可信**：

- **陸股 hard_score 高分** → 反指標（高分 d20 超額中位 −9%、勝率 30%）。
- **陸股打板在「高潮(climax)」階段** → 超額 −1.7%（n=2731）；打板熱的時候追＝虧。
- **陸股龍虎榜熱門股** → 上榜後整體輸大盤 −1.3%；尤其**拉薩散戶在買** −2%、勝率 37%（最該躲）。
- **大戶在賣（持股減少）** → 最乾淨的紅旗（賣的資訊 > 買的）。
- **假集中度（集中度高但法人在賣）／隔日沖爆高** → 兩年都負。
- **法人報告看多（broker_bullish）／YouTube 老師喊看多（無評級）** → 本窗反指標。

> ⚠️ **訂正一個直覺**：價量型「危險訊號」（長上影、爆量長黑、爆量收弱）回測**反而更好**（爆量長黑後每筆 +1.82%）→ **不是陷阱、不可當避雷**。洗盤後再攻最強。

## ⚪ 測過沒料 / 不穩（別期待）

- **籌碼集中度全家族**：台股大戶持股%（S 軌）、徐黎芳法/大戶偷買（W 軌）、分點集中度、**陸股股东户数** → 去 beta 後幾乎沒料、勝率 <50%。
- **龍虎榜當買訊**：機構買、量化買、淨買超、漲多上榜 → train/test 不穩或反指。
- **YouTube 老師明牌**：4 週實證沒人穩贏大盤，許毓玲唯一打平。
- **賣訊（跌破月線/MA10/空頭確認/雙B死叉）**：都「被高估」，事後跌的機率才 ~50%、是落後反指，**不值得一出現就砍**。
- **「找飆股贏大盤」這件事本身**：扣成本後幾乎全輸。

## ⚙️ 紀律/出場：最重要、最少人做（錢坑在這）

- **SOP 端到端（停損守紅K低點 + 最多 20 日出場）**：PF 1.11、勉強正期望，但超額 −0.28% ≈ 追平大盤；70% 交易在賠，全靠少數翻倍。→ **出場紀律比選股更決定盈虧**（3006 證明錢坑在執行不在訊號）。
- **停損／影子帳本／今日最優先卡**：不是選股，是逼自己執行。這才是能穩定「少賠」的地方。

## 陸股情緒：哪個操作模式 × 哪個階段才賺

- **tier A 是唯一正報酬**（超額 +0.45%、勝 50%）；B −0.89%、C −2.07%。
- **低吸 / 波段** 在修復、主升階段正；**打板** 只有修復期 +0.5%，高潮期 −1.7%。
- 結論：**別在熱階段打板，低吸/波段才有相對 edge。**

### 結論（給你的實戰版）
1. **少賠 > 選飆股**：嚴守停損 + 到期出場，這是唯一穩定的優勢。
2. **避開反指標**：不追陸股高分/打板熱/龍虎榜熱門、不信法人老師看多、看到大戶在賣就閃。
3. **真要選股**：台股挑「題材∩三色（最強，+2.7%）/ 三色點火＋雙指標」、陸股挑「三色底反 / 乖離率 / 觀察捕撈」——但心裡知道大多每招只贏大盤約 1%、很薄。
