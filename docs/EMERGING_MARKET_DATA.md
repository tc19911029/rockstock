# 興櫃載圖資料（2026-09-07）

輸入裸代號或 `.TW` / `.TWO` 時，`/api/stock` 先查本地上市櫃主檔；未知代號再查櫃買興櫃名冊。興櫃走獨立路徑，不讀上市櫃 L1，也不讓一般行情 fallback 覆寫。

來源：

- [興櫃基本資料 OpenAPI](https://www.tpex.org.tw/openapi/v1/mopsfin_t187ap03_R)：每日更新名冊，只保存代號與簡稱。
- [官方歷史行情](https://www.tpex.org.tw/zh-tw/esb/trading/info/stock-pricing.html)：`/www/zh-tw/emerging/historical` 按月取得成交股數、高低價與成交均價。
- [官方當日行情](https://www.tpex.org.tw/zh-tw/esb/trading/info/pricing.html)：`/www/zh-tw/emerging/latest` 每分鐘更新，OpenAPI 當日行情作有日期的備援。
- Yahoo chart `events=split`：自動取得換股比例與事件日期。用事件的 `date`，不能用物件索引鍵；6696 事件日期為停止舊股交易的 8/20，恢復新股交易是 8/31。換股事件尚無第二個機器可讀來源交叉驗證，來源失敗時回傳明確錯誤並保留已驗證快取與畫面；不回傳未還原價格，不憑跌幅猜拆股倍數。

原始行情與事件各自保存在忽略提交的 `data/emerging-cache/`。只有圖表回傳時計算事件日前價格除以換股率、成交股數乘以換股率；不改寫原始行情，不把調整值寫入 L1。週、月線先調整日資料再聚合。歷史查詢不使用查詢日之後的事件。月初會以不同快取鍵重新抓上個月，避免把月底盤中快取永久當作完整月份。沒有成交的日期不補零或平線。

興櫃無一般 ±10% 漲跌停規則，且官方無開收盤價。圖表以均價承載 open/close，透過 `priceBasis: esb-average` 在衍生狀態層停用六條件、買賣與型態訊號；顯示標示均價，高低價仍保留。這條資料鏈完全繞開上市櫃漲跌停污染判斷。暫不納入一般上市櫃策略掃描，也不提供分鐘 K。

自動更新是在載入與盤中每分鐘輪詢時進行，並非全興櫃排程下載。輪詢時段為交易日 09:00–15:30，整段重新核對換股事件，避免只更新最後一根而混接不同面額。若行情來源沒有當日資料，保留來源日期與過期標記；中間缺段不再直接標成「停牌」。
