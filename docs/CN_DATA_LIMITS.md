# 陸股（CN）資料覆蓋限制 — 選股/回測前必讀

> 2026-06-14 補。陸股的選股宇宙**先天比台股小**，籌碼/資金資料只覆蓋頭部股。
> 任何 CN 策略（選股、回測、避雷、停損）設計時要知道「哪些資料根本沒有」，
> 不要假設跟台股一樣全市場可用。

## 一句話結論

**陸股目前只夠對「主板大型股」做籌碼選股；中小股、創業/科創、北交所缺資料。**
陸股的可信 edge 在「情緒週期 + 漲停結構 + 龍虎榜」，**不是個股籌碼**（資金流只 8 檔）。

## 對策略的硬規則

1. **CN 籌碼選股的宇宙 = 主板有資金流的頭部股**，不要對中小股期待資金流訊號。
2. **北向資金欄位一律當 0/缺值**（停發），不要當訊號加分。
3. **創業/科創/北交所**：回測/結算要處理 `no_data`；北交所只觀察不操作。
4. **CN 的可信 edge 是情緒/結構層**（見 [[cn_agents_crosstable_findings]]：打板熱階段虧、低吸/波段賺、tier A 唯一正），個股籌碼層不可靠。
5. **CN 出場/停損**（2026-06-14 補）：daily-action 已支援 CN（evaluateHolding 市場無關，上證 000001.SS 當 regime），但**門檻沿用台股、未對 20% 漲停校準**，先當 v1。
