# CH6 進場 — 一致性複審（2026-07-12）

範圍：做多 7 進場位置 = 買法字母 C(6-1盤整突破)/B(6-2回後買)/K(6-3橫盤突破)/N(6-4型態)+D(一字底)/J(6-5 ABC突破)/M(6-6軌道線)/L(6-7飆股黑K)。
問題主軸：CLAUDE.md 鐵則 #10（選股邏輯四方一致）+ CH6 共同鐵則（月線之上＋月線向上、收盤判、大量長紅、設停損）。

## 結論：生產掃描是一致的

- 多頭軌 C/B/K/L/M 必過 Step1 六條件（`matchedMethods` 要含 'A' = `isCoreReady`）。
  - 核心條件② `trendAnalysis.ts` bullishAlign = 三線多排 **且 MA20 向上**（`ma20Rising`）。
  - 核心條件③ = 收盤同時站上 MA10/MA20。
  - → 月線鐵則兩半（站上＋向上）在生產鏈都守住。
- 反轉軌 J 的 detector 自帶兩半 gate（`abcBreakoutEntry.ts:222-224`）→ 全市場掃也守。

所以「掃出來的名單」層面沒有破鐵則。以下是「哪天會爆」的隱患。

## 隱患（現在沒爆是因為被 Step1 遮住）

### 1. detector 自足性不一致（走圖/回測繞過 Step1 時月線鐵則失效）
| 字母 | 站上 MA20 | MA20 向上 | 備註 |
|---|---|---|---|
| J (6-5) | ✅ | ✅ | 自足（移反轉軌時補） |
| M (6-6) | ✅ | ✅ | 自足（被抓到過補） |
| C/B/K (6-1/2/3) | ❌ | ❌ | 靠 Step1；detector 單獨用失守 |
| L (6-7) | ❌ | ✅ 上揚 | 缺站上半條；有 detectTrend 多頭+上揚 |
| D (6-4一字底) | ✅ | ❌ | 缺上揚（一字底均線糾結，上揚半條可爭議） |
| N (6-4型態) | ❌ | ❌ | 全裸，連 detectTrend 都沒有；反轉軌全市場掃 |

團隊自己在 J/M 註解立的標準是「detector 要自足，因為走圖/回測會單獨呼叫」。C/B/K/L 沒跟上這標準。走圖疊圖或不過 Step1 的回測腳本直接叫這些 detector 時，會對「未站上/未向上月線」的標的回傳命中。

### 2. scan-parity 沒鎖任何 CH6 字母（鐵則#10 最大結構破口）
`__tests__/contracts/scan-parity.test.ts` 只鎖排序、MTF weekly gate、處置股 veto。8 個進場 detector 沒有一個有「生產 vs 腳本 vs store」三方一致測試。四方一致純靠人工紀律。
且 `MarketScanner.ts` 把「字母→detector」派工內聯三次（~535 / ~1403 / ~1587），改一處漏兩處 CI 不會亮紅。

### 3. 兩支回測靜默零覆蓋 K/L/J/M/N
`backtest-v12-comprehensive.ts` / `backtest-v12-full-period.ts` 的 CONFIG.letters 宣告了 J/K/L/M/N/O/P/Q，但偵測迴圈只 import 並呼叫 B/C/D/E/F。這些 CH6 字母恆為 0 樣本 → 拿這兩支判 K/L/M/N 績效會誤判「沒訊號」。與生產分岔的第二套派工。

### 4. 常數雙寫 / 量比基準分岔（一致性隱憂，非鐵則）
- N/J/M/D 本地重複宣告 `TRUE_BREAKOUT_PCT`/`ABC_MIN_*`/tolerance 等（值同 bookThresholds 但未 import）→ 日後改一邊漏一邊。
- 主進場 detector 量比基準都用「前日×1.3」（正確）；但同檔的加分/tag 版（`isHighVolume`、`detectMaClusterBreak`）用「5日均量×1.3」。兩套「大量」基準並存。
- 量門檻 1.2（六條件④ 課程投影片）vs 1.3（detector 寶典原文）刻意分家，已有註解，非 bug。

## 待裁決（課程 vs 反轉軌設計）
反轉軌 N（6-4 型態突破頸線做多）課程 6-4 明訂月線鐵則適用，但 N 走 LockWatch、語意是「抓底、突破頸線時常還沒翻多」→ 刻意放寬。要不要至少加 detectTrend 或站上 MA20 提示，需使用者拍板。

## 建議修補優先序
1. 補 scan-parity：對合成 K 線斷言「生產 detector 命中集 == 腳本命中集」，把 8 字母鎖起來（治本，防未來漂移）。
2. C/B/K/L detector 自足化：各補「收盤站上 MA20 + MA20 向上」gate（與 J/M 對齊），純加嚴、生產已被 Step1 擋不改名單，只修走圖/回測繞道。
3. 修兩支 comprehensive/full-period 回測：接生產派工或刪掉死宣告字母。
4. 常數收斂 bookThresholds、量比基準統一。
