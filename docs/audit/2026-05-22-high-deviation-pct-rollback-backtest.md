### 解讀

長窗口顯示 15% 過濾**大幅削減尾部贏家**：
- 「高勝率」+「動能」+「成交額」三大排序因子在長窗口的優勢消失（這些因子原本能抓 15-25% 乖離區間的中段順勢股）
- 「乖離率低」本身就規避高乖離，受影響最小（+95% → +15% 仍為冠軍，但絕對值大降）
- **同樣 ~115 筆交易**：trade count 沒變，但「哪些股票被選」改變了 — 從中強勢股被換成更早期/更低乖離股
- 最大回撤反而**改善** 10pp（57% → 47%），與書本「保守」哲學一致
- 勝率變化不大（37.6% → 34.5%）— **長窗口下 15% 不能拉升勝率**（與 4.5 月窗口結論相反）

**這是與 4.5 月窗口截然不同的訊號**：
- 短窗口：15% 過濾掉部分追高失敗 → 勝率上升、報酬略降
- 長窗口：15% 過濾掉大量趨勢延伸贏家 → 勝率持平、報酬大降
