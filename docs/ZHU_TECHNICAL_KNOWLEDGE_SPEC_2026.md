## 0. 結論先行

RockStock 若要以朱老師體系為核心，不能把全課程壓成一組全域門檻。正確模型是一條有先後順序的決策鏈：

**趨勢與位置 → K 線與均線 → 成交量確認 → 選股淘汰 → 情境化進場 → 事前停損 → 持倉週期管理 → 情境化停利。**

同一個數字在不同章節可能服務不同目的。例如 6.5% 是 K 棒「分類」，2% 是特定進場棒的「最低觸發」，20% 與 15% 則分別屬 CH8、CH9 的不同停利策略。它們不能被整理成單一 `LONG_CANDLE_PCT` 或 `PARTIAL_TAKE_PROFIT_PCT`。

本文件把教材規則保留在原本情境，並將「教材規則」「口述建議」「舊書補充」「RockStock 生產決策」分層，避免不同模型再次把局部規則合併成全域常數。

## 1. 範圍與非目標

本規格涵蓋：

- 趨勢、K 線、均線、成交量的判別點。
- 選股、淘汰、鎖股及排序。
- 做多與做空各七種進場位置。
- 停損、續抱、停利、分批出場及再進場。
- 操作紀律、走圖訓練及可稽核的決策紀錄。

本規格不做以下事情：

- 不宣稱教材案例中的「八成、九成」是經統計驗證的勝率。
- 不把月 5%、年 60% 或六年複利表當績效保證。
- 不因教材有規則就直接認定 RockStock 現有程式已正確實作。
- 不用回測結果改寫老師原意；回測只能形成獨立的 production override。
- 不把 CH12 的 2026 ETF 產品快照混入個股技術分析核心。

## 3. 證據等級與規則狀態

### 3.1 證據等級

| 等級 | 定義 | 可否直接成為 deterministic rule |
|---|---|---|
| A | P0 投影片明印且條件完整 | 可以，但仍須保留章節、方向、週期與狀態。 |
| B | 同課口述／直播明確，但 P0 未印 | 預設只做提示或研究旗標；升為硬規則須另做決議。 |
| C | 舊書明確、P0 未提且不衝突 | 可作補充策略，必須標舊書來源。 |
| D | 圖例敘事、成功率說法、主觀心法或時效資料 | 不可直接硬編。 |

### 3.2 規則狀態

- `exact`：條件、時間窗、比較基準皆明確。
- `context_specific`：數字只屬某章、某方向或某戰法。
- `needs_quantization`：教材概念明確，但沒有可重現的數值門檻。
- `source_conflict`：同一情境的最新來源互相矛盾。
- `education_only`：案例、目標、心理或訓練內容，不是交易 gate。
- `time_sensitive`：商品、費率、排名或法規會變動。

每個 RockStock 規則至少應保存：

```text
rule_id, name, direction, timeframe, strategy_context,
prerequisites, trigger, confirmation_time, invalidation,
stop_rule, exit_rule, evidence_level, source_page,
rule_status, production_override, override_evidence
```

## 4. 全域決策流程

1. **市場與方向資格**：先判大盤／類股／個股，再判多頭、空頭或盤整。
2. **位置資格**：確認價格位於 MA20 正確一側、所在波段不是末端追價區。
3. **候選建立**：用六六大順、特別報價、底部／主升段路徑找候選。
4. **淘汰**：將結構、量能、壓力、背離或法人狀態不佳者剔除。
5. **進場觸發**：只在對應的七種多／空位置，以收盤突破或跌破確認。
6. **風險先決**：送出交易前就決定停損位置、最大損失與部位。
7. **持倉管理**：依短線、長線或分批戰法管理，不可持倉後任意換方法。
8. **停利與退出**：均線紀律、目標壓力與高檔／低檔反轉訊號並行。
9. **事後稽核**：保留「教材規則、實際使用參數、偏離理由、成交結果」。

選股只是候選，進場才是交易觸發；高檔拉回鎖股也不能等同回後買上漲已成立。

### 7.3 飆股專用狀態

- 底部盤整超過 2 個月，配合均線糾結、雙重底、圓弧底、頭肩底等五種圖形鎖股。
- 起漲第一根帶量突破是最佳位置；沒做第一波，再等三種第二波變化。
- 進場小紅 K 以當日低點或固定 5% 停損。
- 最新合集的飆股續抱印為 MA3；不可被一般短線 MA5 自動覆蓋。
- 獲利 >20% 遇高檔爆量黑 K 可先出 1/2；跌破 MA3、頭頭低或出貨型長黑依規則退出。

來源：下冊 CH6-15 p.100–111。

## 10. 行為、訓練與時效模組

### 10.1 操作紀律

- 不向下攤平、不因消息或低估值逆著空頭買進。
- 盤前擬定策略、盤中依計畫、盤後檢討偏差。
- 每日跌幅 >5% 列警示；套牢 10%–20% 與 >20% 分級處理，但不能取代新單事前停損。
- 月 5%、年 60% 只可作資金路徑情境，不得倒推必須交易或宣稱保證。

來源：下冊 CH10 p.178–189、CH11 p.192–199。

### 10.2 林穎走圖 SOP

- 固定四步：選股 → 進場 → 停利 → 停損。
- 練習先遮住未來，先短線後長線；建立每日鎖股與分類觀察清單。
- 大盤、類股、個股三者同向的「三好股」優先。
- 建議至少約 100 張走圖再進實單；初期用固定小額閒置資金、先做一檔。

這一層的用途是驗證使用者是否能重現判斷，不是覆蓋最新合集的數字。

### 10.3 ETF 模組

CH12 由林穎授課，應獨立於個股核心：總報酬優先於配息率，檢查填息、費用、持股重疊與經理人，教材提供 50／30／20 參考配置及 MA20 進出。商品排名、費率、持股與經理人屬 `time_sensitive`，每次決策都要重新查證。

## 13. RockStock 落地契約

1. **教材真意與生產參數分離**：`source_rule` 永不被回測覆寫；另存 `production_override`。
2. **情境鍵不可省略**：至少包含方向、週期、策略、持倉狀態、位置與來源章節。
3. **時間點一致**：使用收盤確認的規則，不可用當日完整 OHLC 回頭產生當日盤中成交，避免未來函數。
4. **候選與交易分層**：鎖股、加分、警示、硬 gate、進場、出場用不同 reason code。
5. **方向不假鏡像**：教材明列不對稱門檻時照原文建模；沒有教做空的段落不能自動反轉生成。
6. **主觀規則不偽量化**：任何 3%、10 日、30 日等工程門檻，若 P0 未給，必須標 `production_quantization`。
7. **回測不證明教材原意**：回測可決定是否上線、提醒或停用，但報表必須同時顯示原規則與偏離原因。
8. **來源可追溯**：每個決策結果都能回到合集印刷頁、口述或書本頁碼。
